# Project Tasks Management System.

A task management application created as practice project as Intern At ALLIED SOFTWARE ENGINNERS Private Ltd.

## Features
- Login
- Admin Dashboard
- Create Task
- Stats (Reports)
- User Friendly

## Technologies

- HTML
- CSS
- JavaScript

## Project Structure

- `assets/` - Images and other assets
- `css/` - Stylesheets
- `js/` - JavaScript files
- `pages/` - Web pages
- `docs/` - Documentation
- `tests/` - Test files
- `screenshots/` - Project screenshots
